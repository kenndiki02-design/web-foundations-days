About QuickNotes

QuickNotes is a simple notes app for jotting down ideas, reminders and to-do items before you forget them. It is designed to be fast, so you spend your time thinking rather than formatting.

How to use QuickNotes

  1. Open QuickNotes and find the "Add a note" form.
  2. Type your note into the text box.
  3. Click the "Add Note" button.
  4. Your note appears in the "Your notes" list.

Features

  • Add a note in seconds
  • See all your notes in one list
  • Live count of how many notes you have
  • Keyboard shortcuts for speed

Keyboard shortcuts

Shortcut Action
Enter Add the note you typed
Tab Move between the input and the button
Ctrl + Z Undo typing in the input
